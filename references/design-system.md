# 编辑风科技新闻设计系统

## 配色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | `#ECEAE4` | 全画布暖灰白 |
| 墨色 | `#1D1D1F` | 标题、正文 |
| 海军蓝 | `#0B1120` | 固定面板、强调卡片、可选字幕胶囊 |
| 橙色 | `#F59E0B` | 只用于关键数字和结论强调 |
| 灰色 | `#8A8F98` | 眉题、次要文字 |

只保留一个强调色。如果数字或结论不是关键信息，就不要上色。

## 字体

- 标题：`Noto Sans SC` 900，82-106px，行高 1.2。
- 正文/字幕：`Noto Sans SC` 600，34-46px。
- 模型名/产品名：`JetBrains Mono`（兜底 `Consolas`）。
- 系统字体要写 `@font-face { src: local(...) }`，HyperFrames 才能正常嵌入。

## 版式

- 画布：1920x1080。
- 场景内容：全屏 flex 纵向排列，`padding: 140px 160px 140px`，`justify-content: center`。
- 内容列：`max-width: 1600px`，`display: flex; flex-direction: column; align-items: flex-start; gap: 36px`。
- 间距要写在内容列内部，而不是只写在场景容器上；否则卡片会贴在一起。
- 卡片：28px 圆角、白底、细边框 `#E4E1D8`，内边距要透气。
- 右侧面板、水印、字幕条都是可选的覆盖层，不是默认配置。

## 动效

- 入场：0.3-0.6 秒，组合 `opacity` 和 `y`（10-40px），有时加 `scale`（0.85-0.9 -> 1）。
- 缓动：`power2.out`、`power3.out`、`back.out(1.6)`；每个场景至少混用 3 种。
- 按旁白节拍错开入场。元素入场后保持静止。
- 场景转场：旧场景约 0.25 秒淡出，空 0.3-0.7 秒，新场景约 0.35 秒淡入。
- 每次场景淡出后加 `tl.set(场景, { visibility: "hidden" }, 结束时间)`。
- 最后一个场景可以在结尾淡出；其他场景在转场开始前必须保持完整可见。
- 装饰性动画只能用有限次循环，例如 `Math.max(0, Math.floor(时长 / 周期) - 1)`。

## 场景结构

每个场景：

1. 眉题（灰色小标签，带橙色短线）。
2. 主标题。
3. 按旁白逐条出现的说明或卡片。
4. 可选的橙色结论/警告块。

讲解类内容建议按“钩子 -> 故事 -> 定义 -> 对比 -> 总结”组织。

## 反模式

- 卡片之间没有间距。不确定就用量化分析确认。
- 未经用户要求就加右侧面板、水印、字幕条。
- 使用超过一种强调色。
- 渐变文字、霓虹紫蓝、深色画布、千篇一律的卡片网格。
- 持续循环动效或硬切。
